# Inventory Management and Billing System

A lightweight, single-page retail showroom application designed for inventory tracking, point-of-sale (POS) billing, and sales reporting. The system manages daily operations from carpet cataloging to checkout, real-time stock deduction, and invoice generation.

---

## 🚀 Features

- **Live Overview Dashboard**: Real-time stats on total models, units in stock, bills generated, gross revenue, and automatic low-stock warnings (≤ 5 units).
- **Inventory Control**: Filterable stock catalog with search by type, size, material, and cost vs. selling price.
- **Purchase & Stock Entry**: Inward stock management supporting photo previews and cost/selling price margin validation.
- **Point of Sale (POS) Checkout**: Visual product selection interface with dynamic total calculation and stock limit safeguards.
- **Printable Invoices**: Built-in print stylesheet to generate clean, printable customer receipts directly from the browser.
- **Sales Analytics**: Filterable sales history by month, year, or custom date ranges with revenue totals.
- **User Management**: Role-based access control supporting Admin and Staff tiers.
- **Zero-Config Persistence**: Fully client-side application backed by browser `localStorage`—no database setup or server installation required.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Flexbox/Grid layout, Print Media Queries)
- **Logic**: Vanilla JavaScript (ES6+)
- **Data Storage**: Web Storage API (`localStorage`)
